# Privacy Policy — Pull Request Risk Scorer

Last updated: 25 November 2026.

Pull Request Risk Scorer is a Forge app for Bitbucket Cloud, built for the Codegeist 2026 hackathon by Princess Ihuoma.

## What the app reads

When a pull request opens, the app reads the pull request through the Bitbucket API, read-only. It reads the changed lines, the files changed, the number of commits, the description, and the author's merged pull request history in that repository. It uses those details only to calculate a risk score from 0 to 100 and to show the reasons behind the score on the pull request page.

## What the app stores

Nothing. The app does not copy or store personal data. It does not keep account IDs, names, or email addresses in its own systems, and it does not cache data for longer than 24 hours.

## What the app never does

The app never writes to your repositories, never changes code, and never shares data with anyone else.
